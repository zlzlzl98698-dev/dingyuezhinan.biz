使用网络代理服务，本质上是把原本直连目标网站的那一段网络流量，先加密转发到服务商管理的入口与出口服务器，再由出口服务器替你向目标站点发起访问。理解这段转交过程中服务商到底能看到什么、看不到什么，以及本地软件配置可能漏掉什么，才能把日常隐私风险控制在合理边界内。

## 代理服务商在技术上能看到的信息

当你打开客户端连上一条节点后，流量先经过本地设备与机场入口之间的加密隧道，再经专线或中转抵达境外出口服务器。作为这段中转路径上的实际运维方，机场服务端在技术上天然具备查看以下几类信息的能力。

第一是你的连接来源与在线时段。入口服务器需要与你的本地设备建立连接，因此能看到你当前的家庭宽带或手机蜂窝网公网 IP 地址、每次上线和断开的时间戳，以及大致的地理位置归属。

第二是访问目标和流量字节数。为了把你的请求准确转发给目标网站，出口服务器必须知道你要连向哪一个目标域名（通过 TLS 握手阶段的 SNI 字段或 DNS 请求获取）或者哪一个目标 IP 地址与端口号，同时也必须实时统计每个账号消耗的上传下载字节数以便面板扣费。

第三是未加密协议下的全部明文。如果你访问的是极少数仍然只支持纯 HTTP 而没有升级 HTTPS 的老旧网页，或者使用未启用加密传输的局域网接口、老旧邮件端口，经过出口服务器的请求路径、网页正文和输入参数都属于明文状态，在技术上可以被中间节点直接读取。

## 端到端 HTTPS 下服务商看不到的内容

好在现代互联网绝大部分主流站点都已经强制启用 HTTPS（基于 TLS 协议加密）。在标准 HTTPS 通信下，浏览器会直接与最终目标网站的服务器协商出一把端到端会话密钥。

这把密钥只在你的本地浏览器和目标网站之间生效，机场的中转入口和出口服务器并不掌握这把密钥。因此，服务商只能看到你连接了某个银行域名、某个 AI 平台域名或某个视频网站域名，却无法解开加密隧道内部的真实内容。你在页面里输入的登录账号、密码、银行卡信息、聊天对话正文、搜索栏里敲下的具体关键词、以及具体打开了该域名下的哪一篇子网页路径，服务商在正常 TLS 环境下均无法直接读取。

不过这里有一个极其重要的例外前提，千万不要忽略浏览器弹出的“您的连接不是私密连接”或“证书不受信任”警告，也绝对不要为了图省事把来源不明的根证书安装进电脑或手机系统的“受信任的根证书颁发机构”里。一旦本机信任了第三方伪造的根证书，攻击者就可以实施中间人解密，届时 HTTPS 加密防护就会形同虚设。

## 无日志声明与客户端透明度的边界

很多机场在推广页面都会写上“绝对零日志”“不记录任何用户浏览记录”之类的字样。理性的判断方式是把这类话当作品牌定位表态，不当成客观技术担保。在真实运维场景里，面板要实现账号到期断开、多设备并发限制、流量倍率扣费以及防恶意滥用封禁，服务端几乎必然要在内存中或短期日志里统计连接数和基础流量元数据。由于本站无法对任何品牌的后端系统进行实机审计，所以数据库不会为任何一家背书“真正无日志”。

在客户端选择上，透明度也有高下之分。使用开源社区维护的通用客户端，例如桌面端的 Clash Verge Rev、FlClash、v2rayN，或者移动端的 v2rayNG、Karing、Hiddify 以及依托官方底座的 Mihomo、sing-box 时，软件不会私下把本地进程列表、安装软件清单回传给某一家特定机场。而使用只提供专属客户端的品牌时，安装和登录过程完全依赖厂商打包好的闭源程序，设备权限与遥测逻辑无法公开校验，详见[安全性评估](/risks/security/)。

## 本地最容易忽视的 DNS 与浏览器泄漏

很多用户花心思挑了专线机场，却在本地配置上把访问记录泄了个精光，最常见的是 DNS 泄漏和 WebRTC 泄漏。

在分流代理模式下，如果本地客户端没有正确配置远程解析或 Fake-IP 机制，浏览器每次敲入境外域名时，系统会先把域名发给本地宽带运营商的 DNS 服务器去问路，等拿到结果或者超时失败后再决定走不走代理。这样一来，本地网络侧对你的访问意图一清二楚，有时还会引发解析污染打不开网页。按照[DNS 设置指南](/guides/dns-settings/)启用客户端增强 DNS（例如 Mihomo 内核下的 Fake-IP 或合理的 Redir-Host 分流），并配合[TUN 模式](/guides/tun-mode/)接管那些不乖乖走系统代理的命令行终端和桌面应用，能显著堵住解析旁路。

另一个常被忽视的口子是浏览器的 WebRTC 功能与扩展权限。部分实时音视频网页或测速脚本会调用 WebRTC 接口绕过普通 HTTP 代理去探测本地网卡地址，导致真实局域网或宽带出口 IP 暴露给目标网页。注重匿名度的场景下，建议关闭或限制浏览器的 WebRTC 暴露策略，并定期清理不常用的浏览器扩展。

## 普通用户日常可落地的五项隐私习惯

保护隐私不需要极客级配置，日常做好这五件小事就能挡住九成以上风险。第一，坚持账号隔离，专门用一个不关联个人身份、工作和金融业务的邮箱去注册机场，并且使用密码管理器生成单独密码。第二，开启浏览器“始终使用 HTTPS”模式，遇到证书警告立刻停止访问。第三，绝对不把订阅链接贴给来路不明的在线订阅转换工具，也不外传包含完整链接的报错截图。第四，敏感的网银、政务和核心工作账号尽量不要和来历不明的[免费节点](/risks/free-service/)混用。第五，使用任何网络工具均应严格遵守所在地法律法规和平台使用条款。
